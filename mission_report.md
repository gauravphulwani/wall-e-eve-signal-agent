# Mission report template

Run `python -m src.main` and copy the actual metrics from `outputs/mission_report.json` and `outputs/evaluation_summary.json`.

Include:
- Mission success/failure
- Steps and energy used
- Number of clues found
- A screenshot of `outputs/path_visualization.png`
- A screenshot of `outputs/performance_graph.png`
- What changed between different seeds
- Limitations and next improvements
